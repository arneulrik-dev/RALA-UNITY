# RALA UNITY

En enkel portal for RALA-appene.

## Første versjon
- RALA GO er tilgjengelig for alle.
- RALA SAFE kan låses for brukere uten aktivt abonnement.
- UNITY inneholder ingen ordre-, prosjekt- eller adminfunksjoner.
- Portalens oppgave er kun å gi én enkel inngang til RALA-appene.

Åpne `app.js` for å sette URL til RALA GO/RALA SAFE og abonnementstatus.
